# Student Dashboard UI

A modern and visually engaging student dashboard interface designed for an educational portal. This project focuses on creating a clean, organized, and user-friendly dashboard layout using HTML and CSS.

## Project Overview

The Student Dashboard UI provides students with a centralized interface to access important academic and financial information. It includes a sidebar navigation, student profile, finance overview, enrolled courses, instructor section, and daily notices.

## Features

* Clean and modern dashboard layout
* Sidebar navigation menu
* Student profile section
* Finance overview cards
* Enrolled courses section
* Course instructor profiles
* Daily notices and exam schedule
* User-friendly interface
* Responsive layout design

## Technologies Used

* HTML5
* CSS3
